# DSH 文件历史与回滚

为 DeepSeek Harness 自动保存每轮工作造成的文本文件变化。需要撤回时，先预览并检查冲突，再由你确认恢复。

## 快速开始

1. 在 DSH 插件管理界面安装 `@guiheng123/dsh-rollback` 并启用。
2. 打开会话中的“文件历史与回滚”插件面板。
3. 选择一轮改动，查看文件差异；选择要恢复的文件并确认。

历史会自动记录，无需让 Agent 运行备份命令。`/file-history` 命令和 `file_history` 工具可用于查看状态与历史；实际恢复、删除记录和更改设置只能由你在插件面板操作。

## 与类似插件的不同

- **按轮次自动记录**：清楚看到每轮新增、修改或删除了哪些文件。
- **恢复前检查冲突**：文件若已被后续工作修改，插件会阻止直接覆盖；写入前还会再验证一次。
- **恢复也留历史**：保留恢复前后的版本，恢复失败时记录逐文件进度，方便检查或再次撤回。
- **遵循 DSH 安全策略**：恢复受会话文件权限限制；有其他 Agent 正在使用工作区时不会恢复。

相比需要手动打快照或主动运行命令的常见方案，本插件把历史与 DSH 轮次关联起来，并把恢复确认留给用户。不同插件实现有差异，此处是设计特点概述，不是对所有同类插件的实测比较。

## 使用范围

- 只备份有效 UTF-8 文本文件；二进制文件无法恢复。
- 默认单文件上限 2 MiB，每次扫描最多 2,000 个文件、总文本量 32 MiB。
- 默认跳过 `.git`、`node_modules`、缓存和构建目录。
- 扫描不完整时会提示，无法确认的变化不会被当作可恢复记录。
- 多文件恢复不是整体原子操作；若中途失败，已完成的文件不会自动回退，但进度会保存在恢复记录中。
- 不替代 Git，也不保存文件权限或目录结构快照。

## 环境与开发

需要 Node.js `>=22` 和 DeepSeek Harness `>=0.2.2-rc.3 <0.3.0`。

```sh
pnpm install
pnpm run check
pnpm test
```
